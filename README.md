# Classy - Learning Management System

**Classy** is a Learning Management System (LMS) designed to enhance the user experience for both students and teachers. With a focus on intuitive design and functionality, Classy provides an easy-to-use platform for academic engagement, assignment submission, attendance tracking, and more.
## Features

### For Students:
- **Account Creation & Login**
- **Browse Subjects and Courses**
- **View and Submit Assignments**
- **Download Attachments**
- **Submit Assignments with Attachments**

### For Teachers:
- **Account Creation & Login**
- **Manage Subjects and Courses**
- **Mark Attendance**
- **Create and Delete Courses**
- **Create Assignments and Monitor Submissions**
## Technologies Used

- **Frontend**: JSP (Java Server Pages), HTML, CSS, JavaScript
- **Backend**: Servlets, Java EE
- **Database**: MySQL
- **Server**: Apache Tomcat
- **IDE**: Eclipse
